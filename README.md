# cursomarcielassis

[![Licença Creative Commons](https://creativecommons.org)](https://creativecommons.org)

Este projeto é um e-book interativo voltado para a Educação Profissional e Tecnológica (EPT). Ele foi desenvolvido seguindo os princípios do Desenho Universal para a Aprendizagem (DUA), unindo conteúdo pedagógico e recursos de acessibilidade.

---

## ♿ Recursos de Acessibilidade (DUA)
* **Libras e Áudio:** Ferramentas integradas para tradução visual e leitura do texto por voz.
* **Adaptação Visual:** Opções de alto contraste, alteração de zoom e fontes adaptadas.
* **Mídias Diversificadas:** Vídeos explicativos e quizzes interativos ao final de cada capítulo.

## 🤖 Recursos de Inteligência Artificial
* **Redação:** Corretor inteligente baseado nos critérios oficiais de avaliação.
* **Matemática:** Resolução passo a passo de questões e desafios lógicos.
